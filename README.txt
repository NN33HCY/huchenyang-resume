胡晨扬 · 产品经理简历（斑马智行）

打开方式：
1. 解压后双击 index.html 即可在浏览器中预览。
2. 建议使用 Chrome / Edge / Safari 等现代浏览器。
3. 首页点击底部五个模块卡片时，会触发高亮 + 涟漪扩散转场动画，随后跳转到对应页面。

页面说明：
- index.html      首页（简历概览 + 模块导航）
- experience.html 工作经历
- education.html  教育背景
- skills.html     核心能力
- insight.html    智能出行洞察
- contact.html    联系我

注意：页面使用了 CDN 加载 Tailwind CSS 和 Lucide 图标，预览时请保持网络连接。
